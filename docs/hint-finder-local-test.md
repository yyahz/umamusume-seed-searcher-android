## 触摸与卡片反馈修正

已用 ADB 实际触摸复现候选项失效：pointerdown 后 WebView 仍合成 mousedown，搜索框 blur 会在 click 前隐藏列表。追加 mousedown 默认行为拦截后，实际连续点选全神贯注、直线能手、百万马力均执行搜索并清空输入，结果分别为 2、26、2 张。

结果概览隐藏；百万马力的 7 张下位白技能卡均有十万马力高亮。360 CSS 像素宽下同列技能框测量均为 150 CSS 像素，无横向溢出。BWIKI 的 sj-an 样式没有固定宽度，本地沿用其底色和圆角并统一同列宽度。截图 .local/hints-lower-fixed.png。

## 分组切换与底部分页

新增筛选下方的金技能／下位白技能切换，仅金技能检索时出现。ADB 实际触摸验证切换、下位第二页、切回金技能再回下位仍保留第二页；仅对应组可见，DOM 仅保留两组各自的底部分页。说明缩短为下位名称和不能获取的上位金技能名称。截图 hints-tier-tabs.png、hints-bottom-pager.png。
